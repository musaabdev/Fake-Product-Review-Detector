# 🤖 Fake Product Review Detector

An AI-powered web application that detects whether a product review is **Fake** or **Genuine** using Machine Learning.

## 🌐 Live Demo

[🚀 Click here to use the Fake Product Review Detector](https://fake-appuct-review-detector-rd9vfdn4f5f4dowjpbzav3.streamlit.app/)


## 📌 Project Overview

Fake online reviews can mislead customers and affect purchasing decisions. This project uses **Natural Language Processing (NLP)** and **Machine Learning** to classify product reviews as either **Fake** or **Genuine**.

The application is built using **Python**, **Scikit-learn**, and **Streamlit**, providing an interactive interface where users can enter a product review and instantly receive a prediction.

---

## ✨ Features

- 🤖 Detects Fake and Genuine product reviews
- 📊 Displays prediction confidence
- 📈 Probability breakdown for both classes
- 🌐 Interactive Streamlit web application
- ⚡ Fast and easy to use

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Fake-Product-Review-Detector.git
```

Move into the project folder

```bash
cd Fake-Product-Review-Detector
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
